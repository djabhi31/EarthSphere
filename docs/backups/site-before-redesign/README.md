# Source snapshot before the site-wide redesign

`earthsphere-source.zip` contains EarthSphere's complete `src` directory immediately before the site-wide redesign on October 3, 2026. It includes the landing work already completed in this conversation.

To compare or recover individual files, extract the ZIP into a separate directory first. Do not overwrite the working tree wholesale unless you intend to roll back the site-wide changes.

The original landing is separately preserved at `/landing-classic`, and the first cinematic design at `/landing-v1`. Their source archives live in the neighboring backup directories.

No GODS EYE VIEW or WORLD MONITOR folder was changed or included in this source snapshot.
