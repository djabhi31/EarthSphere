# README artwork

`readme-banner.png` is a 1600 × 640 editorial graphic created for the repository README. It uses the existing [Earth portrait](../../public/images/landing/earth-portrait.webp), with a composed background, orbit lines, and typography that reflect the current EarthSphere website. It is project artwork, not a screenshot of the application.

The graphic is stored locally so GitHub can display it without a branch-specific raw-image URL. It is a standard PNG; no external fonts, scripts, or embedded web content are required to display it.

The creator portrait shown separately in the README was supplied by the creator; its source is documented in [the portrait notes](../../public/images/creator/README.md). Existing image and data attribution requirements remain applicable.
