# PHASE 17 — Code Quality

- Never rewrite working code unnecessarily.
- Preserve business logic unless an improvement is required.
- Prefer incremental refactoring over complete rewrites.
- Keep components modular and reusable.
- Avoid duplicate logic.
- Follow existing architecture unless a better architecture is justified.


# PHASE 18 — Design Consistency

Before introducing any new component:

- Check whether a similar component already exists.
- Reuse existing design tokens.
- Maintain consistent spacing.
- Maintain consistent border radius.
- Maintain consistent animation timing.
- Maintain consistent typography.

Do not introduce visual inconsistency.
