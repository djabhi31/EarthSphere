## Accessibility

- [ ] WCAG AA
- [ ] Reduced motion

- [ ] Screen reader support

## Final Creative Gate

Before shipping ask:

- [ ] Does this feel like Apple quality?
- [ ] Does this feel unique?
- [ ] Does this feel alive?
- [ ] Would I submit this to Awwwards?
- [ ] Is every interaction intentional?
- [ ] Is there at least one memorable WOW moment on every page?

Only ship when every box is checked.
