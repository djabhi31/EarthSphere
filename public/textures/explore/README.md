# NASA Earth at night

`earth-night.webp` is a WebP conversion of NASA Earth Observatory's 2012 global night-light composite, retained at 3600 × 1800. This is a static basemap, not live imagery. Day/night illumination is calculated separately for the selected UTC time.

Source: https://eoimages.gsfc.nasa.gov/images/imagerecords/79000/79765/dnb_land_ocean_ice.2012.3600x1800.jpg

NASA Earth Observatory / Suomi NPP VIIRS. The existing Blue Marble, water and cloud textures remain unchanged.
