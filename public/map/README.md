# Plate boundaries

`plate-boundaries.geojson` contains the 241 boundary features from the PB2002 dataset. It is the minified JSON representation of the upstream GeoJSON, without geometry edits.

Source: https://github.com/fraxen/tectonicplates/blob/master/GeoJSON/PB2002_boundaries.json

Citation: Peter Bird (2003), *An updated digital model of plate boundaries*, Geochemistry, Geophysics, Geosystems, 4(3), 1027. https://doi.org/10.1029/2001GC000252

Conversion: Hugo Ahlenius, Nordpil. GeoJSON conversion contributed by csterling.
